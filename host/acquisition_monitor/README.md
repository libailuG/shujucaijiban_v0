# 模式20 数据采集上位机

沿用控制模式1上位机的中文深色PyQt6/PyQtGraph界面，独立目录，不替换原程序。

## 启动与接线

根目录双击 start_acquisition.bat，或本目录 run.bat。
本目录 run_simulation.bat 为100Hz模拟数据，不打开真实串口。
启动脚本优先使用 %USERPROFILE%\miniconda3\envs\pyqt\python.exe；其他Python环境先安装 requirements.txt。

预留串口1=JP4/UART4：第3脚PA0 TX → 3.3V TTL USB串口的RX，第1脚GND共地。默认921600 / 8N1，禁用流控，仅接收，不调用串口write；打开前RTS/DTR设为关闭。
选择串口后点击连接。遥控端选择 data2=20、data1.bit0=1 后，主板才以100Hz上报；关闭bit0、退出模式20会停止新帧。连接上位机本身不会切换主板模式或启动采集。

主板需要本次新增时间戳的80字节固件；旧76字节采集帧与模式1的160字节监测帧均不支持。本次未烧录、未进行真实串口连接验证。

## 显示与记录

17个通道按电机、机身、左腿/压力、右腿/压力分组，可逐项或整组选曲线，默认显示6个角度。点击图例线段临时隐藏/显示曲线，刷新不会恢复隐藏状态或新增图例；下方勾选用于加入/移除通道。支持十字线、历史容量、显示时间长度、自动跟随、Y轴缩放、暂停显示、清空缓存、连续CSV记录和缓存导出。
初始缓存12000帧，100Hz约120秒。暂停显示不停止接收和连续记录；清空缓存不清除已记录文件。接收线程与UI批量交换数据，队列容量1000，溢出丢最旧并显示计数。连续CSV在入UI队列之前写入，每50帧刷新，停止/断开时关闭文件。

横轴使用设备微秒时间戳的相对秒数，处理uint32自然回绕。倒退/重启或大于约35.8分钟的歧义间隔会建立新时间段并计数；这不等于可靠检测重启。会话平均帧率使用设备时间，仅作参考。没有设备序号，不能精确统计丢帧或去重。
断开或超过1秒无帧时数值标记不可用，保留历史。主板关闭采集也会产生此状态。

CSV是UTF-8 BOM，列为主机Unix秒、主机monotonic秒、本机接收编号、原始设备timestamp_us及17项原始值。本机编号不是设备序号。CSV始终保存传输单位：角度rad、角速度rad/s、加速度m/s²、压力uint32状态码0..3。

角度直接显示主板已修正结果，不再次取反或减零点。模式20大腿/小腿：左侧raw−π/2、右侧−raw−π/2；右电机角度/速度取反；机身Z加速度含重力。串口2以度上传，与本上位机连接的串口1 rad不同。

帧无有效位和CRC。主板对失效数据清零，上位机不能区分有效零值和失效占位；有限数值只代表可绘制，不表示传感器有效。无全身同步采样保证，timestamp_us为主板读取快照的时间。软件不从单个压力码推导额外受力信息。

## 线协议

80字节小端，Python struct `<2I11fI4fII`：头0xAAAAAAAA、uint32 timestamp_us、11个float32（左右电机角度/速度、机身gyro XY/accel Z、左大腿角度/速度、左小腿角度/速度）、uint32左压力、4个float32（右大腿角度/速度、右小腿角度/速度）、uint32右压力、尾0xEEEEEEEE。
时间戳偏移4，左压力52，右压力72，帧尾76。详见 firmware/RESERVED_UART2_PROTOCOL.md。
解析器按固定长度验证帧头、帧尾及压力码范围，支持分包、粘包、噪声后重同步；载荷中允许出现帧头/帧尾字节。无CRC无法识别保持结构合法的位错误。

## 离线文件标签页

重启程序，切换“离线文件”，点击“打开日志文件”选择同类模式20二进制TXT/BIN/LOG文件。无需连接串口，文件载入和转换在后台线程执行，保留实时采集功能。支持当前80字节、带uint32微秒时间戳的协议；不是普通文本表格，也不兼容旧76字节帧。

载入后显示全部文件时长、帧数、平均频率及解析统计。17路按4组选择，默认显示6个角度；滚轮缩放、拖动平移，“显示全部”恢复全时间范围。鼠标移动时显示最近采样点的设备时间戳和各通道数值。图例可隐藏/显示曲线，Y轴直接显示原始值，不自动换倍率。

“整文件导出CSV”和“整文件导出NPZ”导出所有已解析帧与全部17路通道，不受勾选、隐藏或当前缩放窗口影响。数据不做滤波、插值、再次取反或零点校正，角度保持上传单位rad。解析失败保留上次已加载数据。禁止覆盖原始采集日志。

离线CSV列：time_s（设备相对秒）、timestamp_us（原始uint32微秒）、segment_id（从0开始的时间段编号）及17个原始字段。没有伪造主机采集时间。CSV使用UTF-8 BOM。

NPZ为压缩NumPy归档，可以直接 `np.load(path, allow_pickle=False)` 读取：
- time_s：float64，长度N，处理时间戳自然回绕后的相对秒。
- timestamp_us：uint32，长度N，原始设备微秒计数。
- segment_id：uint32，长度N；检测到倒退/重启或歧义间隔后递增，并以10ms间隔建立新的显示时间段。
- values：float32矩阵，形状(N,17)。channel_names和units记录对应列名及单位。
- 同名通道数组：例如left_motor_angle、left_pressure，便于按字段读取；物理量float32、压力uint32。
- source_file：原始路径；frame_size：80。不需要pickle，不包含虚构的有效位。

协议无CRC和传感器有效位，解析器只过滤帧结构及非法压力码，保留载荷原值；跳过字节/错帧统计仅用于格式诊断。尾部填充和不完整帧不进入CSV/NPZ，不改变原文件。

已使用caiji_data/LOG00126.TXT验证：1561帧、15.614034秒，CSV和NPZ逐项一致，原文件保持不变；离线载入、曲线选择、后台导出、错误文件保留原数据、自然回绕/倒退及源文件覆盖保护测试通过。整个采集上位机当前12项测试通过。
