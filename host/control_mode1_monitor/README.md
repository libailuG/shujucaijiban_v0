# 控制模式1 神经网络监测上位机

> 协议变更（2026-11-16）：当前固件已改为模式1 data1.bit1控制串口1发送52字节SI观测帧。
> 本上位机已支持新协议，默认选择“观测52字节（新固件）”并显示“网络观测 · 国际单位”标签页；旧160字节协议保留为可选项。新协议见 firmware/RESERVED_UART2_PROTOCOL.md。

新标签页将11项观测放在同一张图和同一列表中，不分类，支持单项勾选/全选、实时读数、自动跟随、显示时长、暂停、连续记录与缓存CSV导出。角度rad、角速度rad/s、扭矩Nm，采用网络模型坐标，扭矩为上一周期策略主动命令。新帧没有设备时间戳、序号或有效位，曲线使用电脑接收时间，不推测丢帧或设备计算状态。输入异常时固件暂停上传，上位机1秒无数据标记过期。

离线日志：先断开串口，在“网络观测 · 国际单位”页点击“读取日志文件”，选择52字节二进制TXT/BIN/LOG文件（例如caiji_kongzhi1_data/LOG00128.TXT）。默认显示完整曲线，可缩放、拖动、勾选通道，离线文件保留全部帧，不受实时6000帧缓存限制。文件时间轴按50Hz换算，不能用于确认真实采样间隔或漏帧。界面报告帧数、跳过/尾部字节和错帧候选数；无效文件不会覆盖已加载的数据。

“保存为CSV”“保存为NPZ”可保存当前离线全量数据或当前实时观测缓存。CSV包含time_s、time_basis、host_time与11项观测；离线host_time留空。NPZ可用`numpy.load(path, allow_pickle=False)`读取：values为N×11 float32，keys为对应字段名，time_s为相对秒数，host_time为实时接收时间（离线为NaN），time_basis为nominal_50hz或host_receive_time，source为来源，nominal_sample_rate_hz为50。单位由字段名标明。顶部连续记录功能仍保存实时CSV。

新固件使用：运行run.bat，保持顶部“观测52字节（新固件）”，连接串口。在遥控端发送data2=1、data1.bit1=1；data1=2仅上传、data1=3上传并允许策略扭矩。本程序仍只接收，不发送控制命令。连接期间协议选项锁定；要使用旧固件，断开后选择“监测160字节（旧固件）”。以下关于四元数、网络输出和分类的说明仅适用于旧协议。

独立 Python 桌面程序，中文 PyQt6 + PyQtGraph。参考 `C:\play\pyqtgraph\main.py` 的曲线、定时刷新及启动方式；未修改 motor_monitor 或固件。

## 启动

双击 `run.bat`，选择串口、刷新、连接；双击 `run_simulation.bat` 无硬件体验。默认使用 `%USERPROFILE%\miniconda3\envs\pyqt\python.exe`，不存在则使用 PATH 的 Python。建议 Python 3.10+。

其他环境先 `python -m pip install -r requirements.txt`，然后 `python main.py` 或 `python main.py --simulate`。本机 WindowsApps 的 python 占位入口不可用时请使用实际 Python 完整路径。

## 接线及使用

预留串口1为 JP4/UART4：第3脚 PA0 TX 接 USB串口 RX，第1脚 GND 共地，采用匹配的3.3V TTL串口适配器。程序不使用板端 RX，不调用串口 write，不提供任何控制或模式切换操作。打开串口前关闭 RTS/DTR，禁用软硬件流控；驱动层开启端口时的电平行为需由硬件环境确认。

默认 921600、8N1。主控仅在控制模式1（遥控 UART9 data2=1）以20ms/50Hz上传。当前普通模式无上传是预期行为；hello_world已删除。本软件不会切换模式或注入扭矩。左右始终指穿戴者左/右。

界面采用 `C:\play\pyqtgraph` 相同深色主题、字体、整宽曲线布局及十字线交互。底部按“关节反馈”“机身姿态 / 角速度”“网络观测（11维）”“网络输出 / 扭矩命令”分组。每组可全选/取消，亦可单独勾选；切换标签页保留其他组选择，多组可叠加显示。勾选旁显示对应最新值。点击图例线段临时隐藏/显示曲线，刷新保留隐藏状态且不重复增加图例；下方勾选用于加入/移除通道。单位不同的通道共享纵轴，请按需要选择。四元数为机身到世界 Hamilton；硬件坐标与模型坐标不同。最终驱动扭矩是命令，不是实测值或发送确认。

支持历史帧数（W=10000帧，默认0.6W，最大10W）、历史显示长度、跟随最新数据/恢复跟随、Y轴自动缩放和鼠标十字线。扩大显示时长会按50Hz自动扩大缓存，已经淘汰的数据无法恢复。关闭跟随可固定时间轴观察历史，滚轮缩放、拖动平移。

启动默认打开“网络观测（11维）”，显示左右关节角度/π、左右关节角速度/(4π)，共4条网络观测曲线。

## IMU 姿态标签页

顶部“实时曲线 / IMU 姿态”可切换。姿态页用长方体代表IMU，按上传的Hamilton wxyz四元数将硬件机身坐标旋转到世界坐标，绕中心旋转；青色端面为机身X正方向。机身XYZ轴随姿态旋转，地面及世界参考轴固定。提供立体、正视（从+X看）、侧视（从-Y看）、俯视（从+Z看）。仅改变观察视角，不修改接收数据。

右侧显示原始四元数、三轴角速度及从四元数推导的ZYX姿态角（Roll/Pitch/Yaw，度），这些姿态角与网络重力倾角的定义不同。显示矩阵使用归一化四元数；零四元数、非有限值或模长不在0.5～1.5范围内均拒绝更新。接近Pitch ±90°时欧拉角存在奇异性，长方体仍直接使用四元数旋转。航向来自上传四元数，不额外提供绝对北向校正。

IMU有效位未置位、异常/禁用状态、断开或超过1秒无帧时，数值标记不可用，最后有效模型变暗并冻结；从未收到有效姿态则只显示参考网格。“暂停显示”同时冻结姿态与曲线，接收记录继续；清空和重新连接清除旧姿态。模拟模式提供连续变化且一致的四元数及机身角速度，可无硬件检查。绘制使用Qt CPU投影，无需OpenGL或新增依赖。

“暂停显示”冻结数值/曲线，接收、缓存和记录继续；状态统计继续更新。“清空显示缓存”仅清除历史及曲线，不重置连接统计或已记录文件。断开/超过1秒无帧将数值标记不可用，保留历史曲线供查看。重新连接重置统计与缓存。

连续记录在接收线程写CSV并每50帧刷新缓冲，停止/断开时关闭文件。导出缓存保存最近6000帧（50Hz约120秒）；文件为UTF-8 BOM，包含主机Unix秒、原始序号/时间戳、状态、有效位、计算耗时、全部原始浮点值与每个字段的 `_valid` 列。无效原始零值仍保留用于诊断，分析必须使用有效列。连续记录不受暂停及清空影响。磁盘错误会停止接收并明确报错；异常掉电可能损失未刷新的尾部记录。

## 协议依据与有效性

实现前于2026-11-13重新读取：

- `C:\Users\libai\Desktop\X1\imu_caiji\zhuban_caiji\firmware\App\control_mode1_monitor.h`
- 同目录 `control_mode1.c`、`reserved_uart1.c`，并核对 `reserved_uart1.h` 的921600定义。

v1，160字节，小端 FP32，无校验和。结构格式 `<5Ii2I31fI`：头0xAAAAAAAA、版本1、长度160、序号、微秒时间戳、int32状态、有效位、计算微秒、周期秒，然后 joint_angle_rad[2], joint_speed_rad_s[2], body_quat[4], body_gyro_rad_s[3], joint_angle_norm[2], joint_speed_norm[2], previous_torque_norm[2], body_tilt_norm[2], body_gyro_norm[3], raw_action[2], requested_torque_nm[2], model_torque_nm[2], driver_torque_nm[2]，最后尾0xEEEEEEEE。仅观测最新11维（推理内部65维），观测位于网络mean/std标准化之前。

有效位bit0左反馈、1右反馈、2 IMU、3观测、4网络、5最终命令。状态0正常、1暖机、2禁用、-1输入异常、-2配置异常、-3数值异常。网络位约束原始输出/请求/模型命令，命令位约束驱动命令，非有限值不显示。实际固件异常路径 `monitor_publish(now,0,...)` 不复制硬件字段，即使新鲜位仍然置位，字段也可能为清零值；因此异常/禁用状态全部显示不可用，不会把零当真实测量。

解析器联合检查头/版本/长度/尾，错误候选逐字节重同步，保留半帧并处理粘帧；尾标记可出现在载荷中。没有校验和意味着无法识别保持结构完整的位错误。序号及时间戳按uint32模差处理回绕；大于半个计数范围的倒退标记重启/乱序并建立新基准。序号缺失包含设备丢帧和本机队列溢出的影响，不能据此单独定位故障。超长间隔（时间戳半周期约35.8分钟）无法唯一恢复时间。

接收QThread，UI每50ms批量取数据，无逐帧Qt信号积压；队列1000帧，满时丢最旧并计数，UI历史6000帧。曲线用NaN断开无效点。连续记录在入UI队列之前进行，因此不受UI队列溢出影响；慢磁盘可能影响接收吞吐，需现场验证。

`python main.py --smoke-test`：模拟运行3秒，生成 `simulation_preview.png`、`imu_preview.png` 和 `simulation_export.csv`，自动退出。模拟每10秒包含暖机及异常阶段，可持续观察字段不可用状态。

`python -m unittest -v test_protocol.py test_ui.py test_imu.py`：完整11项检查，额外覆盖Hamilton坐标旋转方向、四元数正负等价、异常四元数、姿态暂停/过期/异常冻结与恢复，以及四种视角绘制。

已完成的实际检查和限制见 `VALIDATION.md`。硬件验收应先只读枚举串口，保持板端普通模式及现有指示灯状态；模式1下真实数据、持续记录性能及USB驱动行为需在授权的硬件环境验证。


Y轴刻度按原始数值显示，禁用自动SI前缀/倍率（例如0.5显示0.5，不显示500配×0.001）。Y轴范围自动适应只调整显示范围，不改变数值。更新后重新启动程序生效。
