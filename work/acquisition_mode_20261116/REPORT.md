# 数据采集模式20修改记录

新增 acquisition_mode.c/.h；模式20串口2持续20Hz反馈8项；bit0控制串口1 100Hz采集帧，压力uint32，完整帧76字节小端。
按用户要求反向右电机、右大腿、右小腿的角度与角速度，左大腿、左小腿保留原始符号；其他量保持对应来源符号。单位rad、rad/s、m/s²。
上行data1.bit6/7沿用此前位号，模式20的聚合含义见固件协议文档。
串口1支持按实际帧长发送，保留模式1 160字节监测；采集默认关闭，退出清除开关，关闭后允许正在发送的末帧完成。
CLI构建及Keil项目均加入新模块；CLI HEX/BIN/AXF输出在firmware/ObjectsCli，Keil Objects旧产物未更新。

- 本目录test.ps1：字段来源、反向符号、rad单位、uint32压力偏移、76字节小端编码、100Hz周期、关闭开关、退出模式、失效数据。
