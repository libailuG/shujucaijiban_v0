# 控制模式2监测上位机

双击项目根目录 `start_control2.bat`，或本目录 `run.bat`。无硬件演示使用 `start_control2_simulation.bat` / `run_simulation.bat`。默认使用 `%USERPROFILE%\miniconda3\envs\pyqt\python.exe`，其他Python环境先安装requirements.txt。建议Python 3.10以上。

## 接线与启动

预留串口1为JP4/UART4：第3脚PA0 TX接USB串口RX，第1脚GND共地，使用3.3V TTL适配器。921600、8N1、无流控。上位机只接收，不发送模式、置零或扭矩指令。

需烧录包含模式2遥测的新固件。通过既有预留串口2遥控发送data2=2，串口1自动以约100Hz上传，不需要额外上传开关。data1.bit0=0只计算不输出，=1允许扭矩输出；data1.bit3强制普通静止。退出模式2停止串口1的模式2帧。

## 显示和保存

六条主曲线放在同一张图，使用各自原始单位、共享纵轴，可逐项勾选：左/右角度rad、左/右角速度rad/s、左/右计算力矩Nm。模型坐标为左保持、右相对原始电机反馈取反，两侧后伸为正。计算力矩是经过当前倍率（默认1.2）、15Nm限幅及两层保护后的本周期计算结果，在扭矩许可门控之前；关闭许可时仍能看到计算力矩。它不是原始网络的两个动作，也不是实测力矩。

额外显示最终驱动坐标命令、扭矩许可、策略状态、两层保护、整轮计算耗时、平均计算耗时、调用周期、倍率和序号。最终驱动命令经过许可门控，右侧由模型坐标取反；它不是发送ACK或电机实际执行值。禁用/异常时状态和有效标志优先，曲线用断点而非伪造零值表示无效输入或计算。

曲线使用设备微秒时间戳，支持约71.6分钟回绕；序号缺口插入断点。检测到时间/序号回退时创建新session，显示时间轴接续并断开曲线。会话拼接处的0.01s间隔仅用于显示，不代表停机时间。串口1忙导致的主动丢帧也会表现为序号缺口，缺口不等于网络漏算。无数据1秒标记过期。

暂停只暂停绘图，接收与记录继续。实时缓存最多12000帧（约120s）；长时间记录请使用“开始保存 CSV”，由接收线程在显示队列前写盘。CSV含电脑接收时间、设备累计时间、session、序号、原始时间戳、状态/有效标志、计算/周期微秒值及10个浮点通道。电脑接收时间不代表设备采样时间。

“导出当前数据 CSV”导出实时缓存或完整离线数据。“读取二进制日志”支持外部串口记录器保存的80字节原始BIN/TXT/LOG，须先断开串口；不支持文本十六进制或其他模式的日志。离线时间使用设备时间戳，不假设每帧恰好10ms。连续记录生成的CSV可在独立的“CSV复盘”页打开，也可用Excel/Python分析。

## 自动连续保存与CSV复盘

- 点击“开始保存 CSV”自动在本上位机目录的 `data` 文件夹创建文件，以北京时间 `YYYYMMDD_HHMMSS_微秒.csv` 命名。不弹出路径选择框，不覆盖已有文件。
- 从接收线程接受开始命令后记录新解析的数据，不补写历史缓存。每帧一行，全部主通道和诊断字段均保存，不受曲线勾选和缓存大小影响。
- 每秒刷新文件缓冲区，包括串口暂无新数据时。“结束保存”、断开或正常关闭会关闭文件；再次开始创建新文件。flush不等于强制磁盘同步。
- 时间列沿用设备累计时间，不以点击保存为零点。暂停绘图不会暂停采集或保存；串口没有新数据时不产生记录行。
- “CSV复盘”页自动检索 `data` 下的CSV，也可打开其他路径，后台加载，不影响实时接收和保存。默认六条主曲线放在同一张图；其他诊断列可勾选。支持全览、缩放、拖动和十字线，原始CSV只读。
- 复盘优先使用 `device_time_s`，其次 `time_s`；若时间不严格递增则使用文件帧序号，保留全部行。支持离线导出中为空的 `host_time`。建议结束保存后打开文件，以查看完整记录。
- 运行 `python -m unittest test_protocol.py test_csv_features.py` 和 `python test_ui.py` 验证自动命名、全部通道、停止/重启、关闭刷新，以及独立复盘。此次仅修改上位机，不涉及固件。

## 帧协议

80字节、小端、IEEE754 float32，Python格式`<5Ii3I10fI`。

| 偏移 | 字段 | 类型 |
|---:|---|---|
| 0 | 帧头0x324D43AA | uint32 |
| 4 | version=1 | uint32 |
| 8 | size=80 | uint32 |
| 12 | sequence，每次尝试上传递增 | uint32 |
| 16 | timestamp_us，采集发布周期起点 | uint32 |
| 20 | status：0正常/1初始化/2禁用/3外部抑制/-1反馈或置零/-2周期/-3数值 | int32 |
| 24 | flags | uint32 |
| 28 | compute_us，最近完成的整轮计算耗时 | uint32 |
| 32 | period_us，最近调用间隔 | uint32 |
| 36/40 | 左右角度rad，模型坐标 | float32×2 |
| 44/48 | 左右角速度rad/s，模型坐标 | float32×2 |
| 52/56 | 左右计算力矩Nm，倍率及保护后、许可前 | float32×2 |
| 60/64 | 左右最终驱动坐标命令Nm | float32×2 |
| 68 | 当前输出倍率 | float32 |
| 72 | 平均整轮计算耗时ms | float32 |
| 76 | 帧尾0xEE324D43 | uint32 |

flags：bit0反馈有效，bit1计算力矩有效，bit2扭矩许可，bit3最终驱动命令有效，bit4内置保护，bit5外部抑制。初始化或异常帧不代表执行了新一次网络推理，计算耗时字段可能保留上一轮值；以status/flags判断有效性。外部抑制期间仍上传有效的零计算力矩。

帧校验使用头/尾、版本、长度、标志和有限浮点值，没有CRC。程序能处理拆包、粘包和重新同步，但无法识别所有保持合法字段的位错误。

## 模式2反馈检查临时旁路（2026-11-17，当前排查固件）

按用户要求，模式2不再因反馈过期、左右时间差、反馈mode或电机error_flag停机，只有置零会触发原反馈失败路径。无反馈或非有限角度/速度时使用最近有限反馈，尚无缓存时为零。遥测flags.bit0只表示有可用缓存，不保证新鲜；模式2的status=-1在此版本表示置零抑制。历史CSV仍按原固件语义解释，其他模式也不受此改动影响。因此上位机保留通用状态标签，需结合固件版本判断。输出许可、周期/数值异常与振荡保护保留。断反馈不再自动停助，本版用于排查。已构建未烧录。

## 模式2系数由data3下发（当前版本）

预留串口2发送data2=2时，data3（float32）直接指定输出倍率；上电默认0。例如data3=0.6为0.6倍，data3=0为零输出，扭矩许可仍由data1.bit0控制。每条模式2指令都必须携带期望倍率；没有新消息时保持最后的值。系数不再限定为八个档位，负数/非有限值按0处理，最终力矩仍限幅±15Nm。系数变化先清除旧命令，下一控制周期使用新倍率。上位机从串口1遥测显示实际倍率；串口2上行data3仍为电压。需烧录更新固件，上位机无需更新。

模式3反馈保护取消（2026-11-17，覆盖此前反馈故障清零说明）：反馈无效/过期、左右时间差、mode错误、error_flag及非有限角度/速度仅记录当前状态和累计故障，不停止正弦、不重置相位；反馈曲线无效时仍不显示无效数值。手动禁止、退出、bit3普通静止及既有置零抑制保持。当前左侧默认3Nm/2秒，右扭矩0，允许出力时两侧KP10；仅模式3生效。未烧录。
