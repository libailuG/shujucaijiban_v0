# 预留串口2协议（2026-11-16）

JP7 / UART9：1 GND、2 PD14 RX、3 PD15 TX、4 3.3V。921600、8N1，20Hz主动上报。
固定48字节，小端：AAAAAAAA、uint32 data1、uint32 data2、float32 data3..10、EEEEEEEE，无CRC。

## 模式与上行

编号均为十进制，按整个data2匹配。上行data2为实际接受模式，未知值回0；传感器掉线不退出已选择的调试模式。

| data2 | 模式 | data3..10 |
|---|---|---|
| 0 | 普通静止 | 电压V、机身Roll°、Pitch°、左电机角度°、右电机角度°、0、0、0 |
| 1 | 控制模式1 | 电压V、左电机角度°、右电机角度°、0、0、左输出命令Nm、右输出命令Nm、0 |
| 11 | 电机调试 | 电压V、左角度°、右角度°、左角速度rad/s、右角速度rad/s、左实测扭矩Nm、右实测扭矩Nm、右实测扭矩Nm |
| 12 | 机身IMU | Roll°、Pitch°、角速度XYZ rad/s、加速度XYZ m/s²（含重力） |
| 13 | 左大腿IMU | 同12排列，使用对应板坐标系 |
| 14 | 左小腿IMU | 同12排列，使用对应板坐标系 |
| 15 | 左压力 | 三路电压V、接触状态码0..3、样本年龄ms、0、0、0 |
| 16 | 右大腿IMU | 同12排列，使用对应板坐标系 |
| 17 | 右小腿IMU | 同12排列，使用对应板坐标系 |
| 18 | 右压力 | 同15排列 |

压力是原始电压，不是力或重量；通道1..3对应采集板原始顺序。IMU不上传Yaw和电压。
控制模式1仍为50Hz计算，20Hz上报，输出命令不是实测值或电机ACK。级联数据不接入策略观测。

## data1位定义

位号从0开始。

| 位 | 下行 | 上行 |
|---|---|---|
| bit0 / 0x01 | 模式11：置零请求；模式1：允许策略扭矩 | 模式11：置零执行闪烁/完成状态；模式1：回显策略允许开关；其他模式0 |
| bit1 / 0x02 | 模式1：开启预留串口1网络观测上传 | 模式1：回显观测上传开关；其他模式0 |
| bit3 / 0x08 | 最高优先级强制普通静止，清目标，不触发新置零 | 未新增回显含义 |
| bit6 / 0x40 | 不作为控制指令 | 模式12..18所选传感器数据有效 |
| bit7 / 0x80 | 不作为控制指令 | 模式12..14、16..17所选IMU姿态有效；压力模式0 |

模式0、1、11的bit6/7为0，不代表其反馈有效性。
传感器样本年龄超过50ms或无效/离线时，字段清零，bit6/7清零；姿态单独无效时仅清Roll/Pitch和bit7，仍可上传有效角速度和加速度。无效压力数据的年龄字段也清零。
策略允许状态不代表实际有扭矩输出，仍受暖机、传感器有效性及置零流程门控。

下行11的data8/9为左右目标扭矩Nm，KP固定50；NaN/Inf目标拒绝整条调试命令并保持已接受状态。上行data10与data9均为右电机反馈扭矩Nm，保留原始符号。
离开11清调试目标，模式1的bit0不作为置零请求。非电机调试帧会清除置零请求边沿记忆。
事件遥控保持，无消息超时退出机制保持不启用。切换模式清策略状态，策略扭矩许可按当前模式1命令的bit0设置，其他模式清除。

## 迁移

旧编号1原为电机调试，现在是控制模式1；旧编号2、3现在回普通。遥控端必须配套升级，无旧编号兼容。
本次只更新主板及说明，未修改遥控端程序，未烧录或操作设备。

## 控制模式1：预留串口1网络观测（2026-11-16）

JP4/UART4，921600、8N1。data2=1时，data1.bit1=1开启50Hz上传，0关闭；上电默认关闭，退出模式或bit3强制普通静止会清除。事件保持，无消息超时关闭。关闭后允许正在发送的末帧完成。bit0仍独立控制扭矩许可：data1=2只上传，data1=3上传并允许扭矩，仍受策略保护条件门控。

该52字节帧替代旧160字节监测帧，不混发。小端，格式 `<I11fI`，无时间戳、序号、CRC或有效位。只上传有效策略更新（含零输出暖机），输入异常/置零/周期异常期间暂停，恢复后重新暖机。忙时丢弃当帧，不积压。

| 字节偏移 | 类型 | 内容 |
|---|---|---|
| 0 | uint32 | start_flag=0xAAAAAAAA |
| 4 | float32 | 左关节角度 rad |
| 8 | float32 | 右关节角度 rad |
| 12 | float32 | 左关节角速度 rad/s |
| 16 | float32 | 右关节角速度 rad/s |
| 20 | float32 | 上一周期左主动扭矩命令 Nm |
| 24 | float32 | 上一周期右主动扭矩命令 Nm |
| 28 | float32 | 前后倾斜角 rad，前倾为负 |
| 32 | float32 | 左右倾斜角 rad，右倾为正 |
| 36 | float32 | 腰部模型X轴角速度 rad/s |
| 40 | float32 | 腰部模型Y轴角速度 rad/s |
| 44 | float32 | 腰部模型Z轴角速度 rad/s |
| 48 | uint32 | end_flag=0xEEEEEEEE |

全部使用模型坐标与国际单位制，来自本次推理所用观测的最新11维，去掉π、4π、40尺度系数，未做mean/std标准化。左右为穿戴者视角，右关节角度/角速度已取反；腰部模型坐标X右/Y前/Z上，角速度相对机身坐标为[-Y,X,Z]。上一周期扭矩是限幅后的模型主动命令（当前默认±20Nm），不是实测扭矩或驱动方向值；即使bit0关闭，策略仍计算并更新这项历史。

原 host/control_mode1_monitor 仅支持旧160字节协议，需要配套适配后使用。

## 数据采集模式 data2=20

下行data1.bit0是持续上传开关：1开启预留串口1采集上报，0关闭；模式20默认关闭，退出模式或bit3强制静止会清除开关。再次进入按当前有效下行帧bit0决定是否开启。上行data1.bit0回显开关状态，不代表发送完成。
模式20不下发调试/策略扭矩，不触发置零；电机继续原有静止查询。

预留串口2无论采集开关是否开启，都以20Hz主动反馈：

| 字段 | 内容 |
|---|---|
| data3 | 左电机角度° |
| data4 | 右电机角度°，取反 |
| data5 | 左大腿X角度° |
| data6 | 左小腿X角度° |
| data7 | 左压力接触状态0..3，float32表示 |
| data8 | 右大腿X角度°，取反 |
| data9 | 右小腿X角度°，取反 |
| data10 | 右压力接触状态0..3，float32表示 |

模式20上行data1.bit6=上述8项全部有效；bit7=四块大腿/小腿板X姿态及其对应角速度均有效。该状态不包含未在串口2上报的机身IMU健康状态。

预留串口1（JP4 / UART4，1 GND、2 PA1 RX、3 PA0 TX、4 3.3V）保持921600、8N1。
开启后按100Hz发送80字节小端帧，包含uint32微秒时间戳，无CRC或序号，不额外插入有效位，严格按以下顺序：

| 字节偏移 | 类型 | 内容 |
|---|---|---|
| 0 | uint32 | start_flag=0xAAAAAAAA |
| 4 | uint32 | timestamp_us，主板微秒计时器 |
| 8 | float32 | 左电机角度rad |
| 12 | float32 | 左电机角速度rad/s |
| 16 | float32 | 右电机角度rad，取反 |
| 20 | float32 | 右电机角速度rad/s，取反 |
| 24 | float32 | 机身X角速度rad/s |
| 28 | float32 | 机身Y角速度rad/s |
| 32 | float32 | 机身Z加速度m/s²，含重力 |
| 36 | float32 | 左大腿X角度rad |
| 40 | float32 | 左大腿X角速度rad/s |
| 44 | float32 | 左小腿X角度rad |
| 48 | float32 | 左小腿X角速度rad/s |
| 52 | uint32 | 左压力接触状态0..3 |
| 56 | float32 | 右大腿X角度rad，取反 |
| 60 | float32 | 右大腿X角速度rad/s，取反 |
| 64 | float32 | 右小腿X角度rad，取反 |
| 68 | float32 | 右小腿X角速度rad/s，取反 |
| 72 | uint32 | 右压力接触状态0..3 |

X角度使用对应级联板Roll，X角速度使用其陀螺仪X；机身使用已安装校正的机身坐标。压力状态直接使用采集板原始status。

模式20四块大腿/小腿的角度先修正方向，再减90°零点：左侧=原始Roll−π/2，右侧=−原始Roll−π/2（rad）。串口1上传此rad值，串口2再乘180/π转为度。故左侧原始+90°、右侧原始−90°时上传为0。角速度只修正方向，不减零点；电机角度不应用此零点。模式13/14/16/17的原始IMU调试上报保持原定义。
timestamp_us取自本次主板读取快照开始时的imu_time_us()，uint32约71.6分钟回绕；不代表每块采集板各自的原始采样时刻。每次取各路最新一致快照，并非跨所有板硬件同步采样。电机反馈超过30ms、机身或级联数据超过50ms视为过期；对应无效数据清零，姿态无效只清角度。串口1帧无单独有效性字段，零值本身不能区分失效与合法零值。
关闭或退出模式后不创建新的采集帧，已经开始发送的一帧完整发送结束，避免留下半帧。发送忙时跳过当次帧，计入g_uart1_tx_drop_count，不补发积压周期。
模式1原有160字节/50Hz监测帧保留，两种帧按模式互斥；切换时原帧可能先发送完。接收端应按当前模式选择帧长度，帧头帧尾相同。
